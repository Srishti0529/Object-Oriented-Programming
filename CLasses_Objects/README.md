# 📘 Objects and Classes in Java (OOP)

## 📌 Introduction

Objects and Classes are the foundation of Object-Oriented Programming (OOP).

* A **Class** is a blueprint or template used to create objects
* An **Object** is an instance of a class that contains data and behavior

---

## 🧱 Class

### 📖 Definition

A class is a user-defined data type that defines properties (variables) and behaviors (methods).

### 🔹 Key Components:

* **Variables (Data Members)** → Store data
* **Methods (Functions)** → Define behavior
* **Constructors** → Initialize objects

---

## 🎯 Object

### 📖 Definition

An object is a real-world entity created from a class.

### 🔹 Characteristics:

* **State** → Represented by variables
* **Behavior** → Represented by methods
* **Identity** → Unique reference

---

## ⚙️ Relationship Between Class and Object

* Class = Blueprint
* Object = Actual implementation
* Multiple objects can be created from one class

---

## 🔄 Object Creation Process

1. Declare a reference variable
2. Create object using `new` keyword
3. Initialize using constructor

---

## 🧩 Example Concept

* Class defines structure
* Object uses that structure to store real data

Example:

* Class: Student
* Objects: Student1, Student2

---

## 🧠 Key Concepts

* **Encapsulation** → Binding data and methods together
* **Abstraction** → Hiding implementation details
* **Reusability** → Same class used to create multiple objects

---

## ✅ Advantages

* Improves code organization
* Promotes reusability
* Makes code modular and maintainable
* Models real-world entities easily

---

## ❌ Disadvantages

* Can increase complexity for beginners
* Requires proper design planning

---

## 📌 Conclusion

Classes and objects are the core building blocks of Java. They help in structuring programs efficiently by modeling real-world entities and promoting reusable and maintainable code.
