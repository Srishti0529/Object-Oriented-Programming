# Abstraction in Java (OOP)

## Definition

Abstraction is the process of hiding implementation details and showing only essential functionality to the user. It focuses on **what an object does** instead of **how it does it**.

---

## Real World Example

A car is a common example of abstraction:

* You use steering, brake, and accelerator
* You don’t see how the engine works internally

Only important features are exposed, and internal complexity is hidden.

---

## Why Use Abstraction

* Hides complex implementation
* Improves code readability
* Reduces dependency between classes
* Enhances security by hiding internal logic
* Makes code easier to maintain and extend

---

## How Abstraction is Achieved in Java

Abstraction is implemented using:

* Abstract Classes
* Interfaces

---

## Key Characteristics

* Abstract classes cannot be instantiated
* Abstract methods do not have a body
* Subclasses must provide implementation
* Supports runtime polymorphism
* Promotes loose coupling

---

## When to Use Abstraction

* When multiple classes share common behavior
* When you want to define a blueprint for subclasses
* When implementation may change but behavior remains same
* When hiding complex logic is required

---

## Summary

Abstraction simplifies programming by hiding unnecessary details and exposing only required functionality. It helps build flexible, maintainable, and scalable object-oriented applications.
