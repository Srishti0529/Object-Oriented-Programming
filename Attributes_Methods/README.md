# 📘 Attributes and Methods in Java (OOP)

## 📌 Introduction

Attributes and Methods are essential components of a class in Object-Oriented Programming (OOP).

* **Attributes** represent the data or properties of an object
* **Methods** represent the behavior or actions of an object

Together, they define how an object looks and how it behaves.

---

## 🧱 Attributes (Variables)

### 📖 Definition

Attributes are variables declared inside a class that store the state or data of an object.

### 🔹 Types of Attributes:

* **Instance Variables** → Defined inside a class, unique for each object
* **Static Variables** → Shared among all objects of a class
* **Local Variables** → Declared inside methods

### 🔹 Example Concept:

* Class: Student
* Attributes: name, rollNo, marks

---

## ⚙️ Methods (Functions)

### 📖 Definition

Methods are functions defined inside a class that perform specific tasks or define the behavior of objects.

### 🔹 Types of Methods:

* **Instance Methods** → Work on instance variables
* **Static Methods** → Belong to class, not objects
* **Parameterized Methods** → Accept inputs
* **Non-Parameterized Methods** → No inputs

### 🔹 Example Concept:

* Methods: display(), calculateMarks(), updateDetails()

---

## 🔄 Relationship Between Attributes and Methods

* Attributes store data
* Methods operate on that data
* Methods can read and modify attributes

---

## 🧠 Key Points

* Attributes define the **state** of an object
* Methods define the **behavior** of an object
* Both are defined inside a class
* Methods can access attributes directly

---

## 🎯 Real-World Example

For a **Car**:

* Attributes → color, speed, model
* Methods → start(), stop(), accelerate()

---

## ✅ Advantages

* Helps organize code clearly
* Improves readability and structure
* Supports encapsulation
* Makes programs modular

---

## ❌ Disadvantages

* Requires proper design
* Overuse may increase complexity

---

## 📌 Conclusion

Attributes and methods are the building blocks of a class. Attributes define what an object is, while methods define what an object can do, making them essential for designing structured and efficient programs.
